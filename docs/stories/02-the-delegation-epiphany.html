1. The Core Insight: Event Bubbling

Every browser has a built-in superpower that developers often forget: Event Bubbling.

When a user clicks a button inside a card or table row, the click event does not stay on the button. It bubbles upward through every ancestor in the DOM tree until it reaches document: 

[ <button class="btn-action"> ] ──(bubbles up)──> [ <div class="card"> ] ──> [ <div id="container"> ]
                                                                                   ▲
                                                                                   │
                                                      Attach ONE listener here ────┘

Instead of attaching 500 listeners to 500 buttons, attach exactly 1 listener to the parent container!

2. The Three Pillars of Delegation

1. The Anchor

The stable parent element (container ID or DOM element) that lives throughout the page lifecycle.

2. The Interceptor

A single listener per event type (e.g. click) that catches events as they bubble up.

3. The Matcher

event.target.closest(selector) checks if the clicked element matches the target selector.

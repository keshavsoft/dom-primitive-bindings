1. The Declarative Transformation (v3)

In v3, event bindings are completely decoupled from JavaScript code. Instead of writing imperative JS handlers, your events are declared in a clean, serializable bindings.json file: 

// bindings.json
[
  {
    "event": "click",
    "selector": ".btn-show"
  },
  {
    "event": "keydown",
    "selector": "input[type='search']"
  }
]

Your application simply imports this JSON and feeds it to bindEvents.

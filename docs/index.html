The Event Delegation Story

Traditional web apps attach addEventListener to individual buttons, inputs, and rows. When rows are re-rendered, paginated, or filtered, listeners are either lost or accidentally duplicated, creating memory leaks and stale event handlers.

DOM Primitive Bindings inverts this pattern. Exactly one listener per event type is attached to the parent container (e.g. #table-container or #form-container). When an event occurs, it bubbles to the container, checks for matched selectors via closest(selector), and dispatches to the registered runner. New DOM elements added at runtime work immediately with zero re-binding!

Staged Architecture in src/v1/

1. guards/

Validates inputs before any DOM mutation occurs. Separated into container/ (validates first input) and bindings/ (validates second input array).

2. prepare/

Groups bindings by event type into a Map<eventType, bindings[]>, ensuring only a single listener is registered per event type.

3. listeners/

Attaches container event listeners that intercept bubbling browser events and pass them down into the dispatch pipeline.

4. dispatch/

Finds the matching target via closest(selector), resolves start inputs, executes the runner, and emits extracted data to onExtract.

Browser Usage via window.ks

Include the bundled distribution or ES module, then call bindEvents: 

<script type="module" src="/docs/dist/v1/min.js"></script>
<script type="module">
  const bindings = [
    {
      event: "click",
      selector: ".btn-delete",
      runner: (target) => ({ id: target.dataset.id }),
      onExtract: (data) => console.log("Deleted:", data)
    }
  ];

  window.ks.domPrimitiveBindings.bindEvents("container-id", bindings);
</script>

Code Conventions

  • Every folder has an index.js file acting as its public gateway.
  • Single-function default export per file (no default export objects).
  • Zero comments in code: Folders and file names tell the story directly.
  • Independent sibling package: Focused purely on event delegation without mixing extraction concerns.

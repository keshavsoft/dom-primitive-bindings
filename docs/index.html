What is DOM Primitive Bindings?

DOM Primitive Bindings is a pure wiring layer for modern web applications. Instead of querying DOM elements and attaching dozens of individual addEventListener callbacks across your codebase, you declare your event interactions in a simple, human-readable JSON contract (bindings.json).

A single root container catches all bubbling events, matches targets with native closest(selector), and dispatches to your clean actions with zero memory leaks, zero dead zones on dynamic re-renders, and zero spaghetti wiring.

Usage & Available Builds

Zero dependencies. Drop into any HTML page via GitHub Pages CDN, ESM import, or NPM package.

GitHub Pages Direct CDN Links

Hosted directly from this repository's GitHub Pages. Include as a module in any HTML file without installing anything. 

<script type="module" src="https://keshavsoft.github.io/dom-primitive-bindings/dist/v4/min.js"></script>
<script type="module" src="https://keshavsoft.github.io/dom-primitive-bindings/dist/min.js"></script>
import { bindEvents } from "https://keshavsoft.github.io/dom-primitive-bindings/dist/v4/min.js";
<script type="module" src="https://keshavsoft.github.io/dom-primitive-bindings/dist/v3/min.js"></script>

NPM Package Installation

Install into bundled Node/Vite projects via npm:

npm install dom-primitive-bindings

5-Line Quick Start

Define your JSON instructions and bind your container in 5 lines:

import { bindEvents } from "https://keshavsoft.github.io/dom-primitive-bindings/dist/v4/min.js";
import bindings from "./bindings.json" with { type: "json" };

// Attach delegated listeners to the container
bindEvents("app-container", bindings);

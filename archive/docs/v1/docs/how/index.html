Chapter 2: The Solution

How We Achieved It

The delegation epiphany and the four-stage decoupled pipeline.

The 3 Pillars of Event Delegation

1. Parent Anchor

A single, stable container element holds one listener. It never gets torn down during child re-renders.

2. Event Bubbling

Clicks anywhere inside the container naturally propagate upwards through standard DOM event propagation.

3. Selector Matching

event.target.closest(selector) accurately finds the intended target even when inner icons or spans are clicked.

The Decoupled 4-Stage Pipeline

To prevent messy side effects, the engine divides event delegation into four disciplined, independent stages:

Stage 1

guards/

Validates that the container element exists in the DOM and filters the bindings array. If any required check fails, execution aborts safely with no half-baked listeners.

Stage 2

prepare/

Groups the flat array of bindings by their event type (e.g., click, keydown) into a high-performance Map lookup.

Stage 3

listeners/

Attaches exactly one listener per event type to the root container. If you have 50 click actions, there is still only 1 browser listener created.

Stage 4

dispatch/

When a user interacts, this stage matches the target using closest(selector) and executes the corresponding callback with full event context.

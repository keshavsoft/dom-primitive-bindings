The Single Responsibility of DOM Primitive Bindings

dom-primitive-bindings is strictly the wiring layer:

  • What it does: Attaches 1 container listener per event type, resolves bubbling targets via closest(selector), and invokes your runner with { event, targetElement }.
  • What it NEVER does: DOM manipulation (no element creation, deletion, or resetting) and data extraction (no reading table rows/cells or building schema objects). For data extraction, use dom-primitive-engine.

The V3 Architecture: Pure JSON Bindings

In V3, you no longer write imperative JS event arrays. Everything is declared in a serializable bindings.json file: 

[
  { "event": "click", "selector": ".btn-show" },
  { "event": "keydown", "selector": "input[type='search']" }
]

The JavaScript runtime simply reads the JSON and executes window.ks.domPrimitiveBindings.bindEvents(container, bindings)!
